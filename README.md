## 🚀 Sobre mim

Sou estudante de Engenharia de Software com foco no desenvolvimento de aplicações web utilizando React, Next.js, TypeScript e Node.js. Possuo experiência prática em projetos Full Stack, criação de APIs REST, integração com bancos de dados e versionamento de código com Git. Também tenho interesse em desenvolver aplicações organizadas, com código limpo e de fácil manutenção. Estou sempre estudando novas tecnologias, criando projetos para colocar em prática o que aprendo e buscando melhorar minhas habilidades em Front-End, Back-End e boas práticas de desenvolvimento. Meu objetivo é continuar evoluindo como Desenvolvedor de Software, contribuindo para projetos que gerem valor e aprendendo continuamente com novos desafios.
